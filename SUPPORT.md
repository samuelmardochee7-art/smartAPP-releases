# Obtenir de l'aide

## 1. Dans l'application

Appuyez sur **F1**, ou cliquez sur **Aide** dans le menu de gauche. L'aide de l'écran
affiché s'ouvre, avec des liens vers le manuel, votre guide rapide et les questions
fréquentes.

## 2. La documentation

Elle est installée avec l'application : menu Démarrer → SmartPresence → Documentation.

| Document | Pour qui |
|---|---|
| [Guide rapide : faire l'appel](docs/guides/guide_appel.md) | Enseignants, surveillants |
| [Guide rapide : secrétariat](docs/guides/guide_secretariat.md) | Secrétariat, scolarité |
| [Guide rapide : administrateur](docs/guides/guide_administrateur.md) | Administrateur |
| [Questions fréquentes](docs/faq.md) | Tout le monde |
| [Manuel utilisateur](docs/manuel_utilisateur.md) | Tout le monde, référence complète |

## 3. L'administrateur de votre établissement

Pour un mot de passe oublié, un compte bloqué ou une question d'organisation,
adressez-vous à l'administrateur SmartPresence de votre établissement.

## 4. L'assistance SmartPresence

L'administrateur de l'établissement peut contacter l'auteur de SmartPresence :

- **E-mail :** samuelmardochee7@gmail.com
- **Téléphone :** +225 01 72 75 57 07

Indiquez :

- ce que vous faisiez, et le message exact affiché ;
- la version, affichée dans l'aide (**F1**) ;
- le fichier `erreurs.log` en cas de message « erreur imprévue ». **Aide** → **Ouvrir le
  dossier des données** l'affiche. Il ne contient que des traces techniques.

**Ne transmettez jamais** de mot de passe, le code de récupération, la base de données, une
sauvegarde, ni des noms, matricules ou photos d'étudiants.

Une faille de sécurité se signale de la même façon, en privé, par e-mail. Les protections
en place sont décrites dans [docs/securite.md](docs/securite.md).
